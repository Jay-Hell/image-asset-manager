# Image Asset Manager 1.2.0 — App Store text

macOS only. Version 1.2.0, build 6 (the released copy is 1.1.0, build 5).

## What's New in 1.2.0

Organise your library by client and project, from the sidebar or from Claude Code.

- The sidebar groups projects under their client, with a count for each, and an Unfiled list shows every image not yet in a project.
- Create, rename, move and delete clients and projects with a right-click, or drag a project onto another client.
- Drag images onto a project to file them. Hold Option as you drop to move them out of the project you're viewing.
- Select images the Mac way: Command-click, Shift-click, Command-A and Escape.
- A tag manager lets you rename, merge and delete tags.
- The grid uses cached thumbnails, so large libraries scroll smoothly.
- The spend dashboard can include or leave out the cost of images made outside the app.
- Claude Code can now create clients and projects, file images into them, list your tags, and import images made elsewhere with their prompt and cost. If the app isn't running, it opens it.
- The connection between Claude Code and the app no longer drops if the app is opened twice.

Your library is upgraded the first time you open it, after a backup is taken, and your keys carry over unchanged.

## Privacy manifest (PrivacyInfo.xcprivacy)

No change needed, checked against `origin/develop` at `a5f9f7c`:

- **UserDefaults** (CA92.1) is still the only required-reason API. It now also holds the import mode and naming choices, which are the app's own settings.
- **No new required-reason APIs:** no file-timestamp, boot-time, disk-space or active-keyboard APIs. The thumbnail cache's daily sweep keeps its own date and reads no file timestamps.
- **Entitlements:** unchanged. The only Info.plist change since 1.1.0 is `ITSAppUsesNonExemptEncryption = NO`.

## Downgrade safety

A library upgraded by 1.2.0 (database v10) still opens and works in 1.1.0. See `scripts/downgrade-check/` and the result recorded in the repo `CLAUDE.md`.
